# ⏳ Countdown Timer in Python

This is a simple countdown timer written in Python. You can input the duration in seconds, and it will count down to zero, displaying the time in `MM:SS` format.

## 📋 Features

- Input-based countdown duration
- Displays timer in real-time using `MM:SS` format
- Handles invalid input (negative or zero)

## 🧑‍💻 Usage

1. Clone this repository or download the script.

2. Run the script using Python:

```bash
python countdown_timer.py

    Enter the number of seconds you want the timer to run.

Example:

Enter the time in seconds: 10

The script will count down from 10 seconds and display "Timer Completed!" when done.
🛠 Requirements

    Python 3.x

No additional libraries are needed.
